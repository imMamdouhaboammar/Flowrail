# Security

Report a suspected vulnerability privately through [GitHub Security Advisories](https://github.com/imMamdouhaboammar/Flowrail/security/advisories/new). Include the affected revision, the relevant command or interface, the impact, and a minimal sanitized reproduction. Remove credentials and proprietary source from reproductions.

Flowrail is an experimental preview. Use a disposable checkout to try MCP edit operations, and treat output as advisory until you check it against the source and compiler.
